# 🧱 Système de couches (C1 → C4)

> Vu ≠ étudié ≠ mémorisé ≠ maîtrisé. **Pendant le semestre : C1 + C2. Au recouchage (26/11 → 09/12) : C3 puis C4 pour toute l'unité.**

## Les 4 couches

| Couche | Quand | Objectif | Méthode | Durée |
|---|---|---|---|---|
| **C1 — Apprentissage** | Semestre (07/10 → 24/11) | Comprendre, structurer, relier | Lecture active → plan en 1 page → mécanismes expliqués à voix haute → **créer les flashcards** → 5–10 QCM | ½ à 2 blocs selon le volume |
| **C2 — Consolidation** | Semestre, quelques jours après la C1 | Rappel actif, corriger les lacunes | **Page blanche** (restituer le plan sans regarder) → corriger → **10–20 QCM** → compléter les flashcards | ~40 % du temps de C1 |
| **C3 — Maîtrise** | **Recouchage passage 1** (jeu 26/11 → jeu 03/12) | Rapidité, pièges, points très tombables | QCM d'annales du cours → **carnet d'erreurs** → tableaux comparatifs | ~30 % du temps de C1 |
| **C4 — Pré-examen** | **Recouchage passage 2** (ven 04/12 → mer 09/12) | Ultra-rapide, intégration | Fiche 1 page + carnet d'erreurs + cas cliniques + QCM chronométrés | 15–30 min/cours |

Entre la C2 et le recouchage, le cours reste vivant grâce aux **flashcards quotidiennes** (15–20 min) et aux **rappels intégrés** du mercredi.

## Quand faire la C2 (en jours après la C1)

| Priorité | C2 |
|---|---|
| **P1** (≥ 30 QCM) | J+1 / J+2 |
| **P2** (20–29, et cours sans chiffre) | J+2 / J+3 |
| **P3** (10–19) | J+3 / J+5 |
| **P4** (< 10) | J+5 / J+7, groupée avec d'autres petits cours |
| **Modules** | J+3 (Para : J+2) |

**Après la C2 :** QCM < 60 % ou page blanche < 50 % → **🔥 À revoir** : C2 bis à J+2. Sinon, le cours attend le recouchage (flashcards seulement).
